# 使用说明

## 时钟

启动默认进入时钟，使用电脑当前本地时间与时区，显示时分秒、年月日、星期和本地黄历。黄历包括农历日期、干支日、生肖、节日或节气，以及今日宜忌。修改电脑时间后，显示会随之更新。

## 秒表与正计时

选择秒表或正计时后点击开始。暂停后可继续，重置归零。秒表显示百分之一秒。超过一小时会显示小时。

## 倒计时

选择倒计时，填写分钟和秒，再点击开始。最长 5999 分 59 秒；运行时无法修改目标时间。归零后显示“时间到”，点击重置可重新开始。当前版本没有到时声音。

## 显示与窗口

顶部调色盘可选择十四种样式，双列菜单包含经典五款，以及巨幕极简、星舰中枢、星尘聚时、电路脉冲、故障电压、酸性涂鸦、光速轨迹、三体星轨、光谱脉冲九款新增样式。切换样式不会中断正在运行的计时，关闭后会记住最后选择。右下角图片按钮选择背景或恢复该样式的原始背景。图钉按钮控制置顶；全屏按钮或 F11 适合投屏，Esc 退出全屏。

背景选择中提供二十张静态壁纸，可滚动浏览；新主题从“银河穹顶”开始，选择后自动保存，重新启动仍会使用。背景按比例居中覆盖，超宽屏和竖屏会裁切部分画面。新增十张原图实测 1672×941，在 4K、8K 屏幕上会放大，不能保证原生清晰度，详见 [壁纸说明](wallpapers.md)。

全屏时画面会铺满当前显示器，顶部操作栏平时隐藏，鼠标移动后暂时显示。时钟、日期和黄历会根据屏幕尺寸自适应；布局支持 1080p、2K、4K 和 8K 视口，背景画质由原图像素与显示分辨率共同决定。

拖动标题栏移动窗口。鼠标移到四角出现斜向缩放光标，按住左键拖动，整个窗口保持 100:71 比例。窗口最小约 480×341，最大宽度 1600；不会超过当前显示器工作区域。全屏时居中显示并保持内容比例。

顶部锁图标用于设置和启用应用锁，密码为 4 至 16 位数字。设置密码后点击锁图标会进入 kiosk 全屏锁定，隐藏窗口按钮、模式切换、计时控制、背景选择、任务栏入口和缩放入口；锁定时普通键盘输入、快捷键和右键菜单都会被应用拦截。鼠标移动只会暂时显示顶部锁图标，锁按钮会与屏幕右边缘保持间距。点击锁图标后输入数字密码并按回车解锁。该密码只保护 DAYAN 时钟窗口，不是 Windows 系统登录密码。`Ctrl+Alt+Delete` 属于 Windows 安全桌面，无法由普通桌面应用拦截；任务管理器等入口需要系统策略配合。

## 设置与系统自检

点击顶部带齿轮图标的“设置”，菜单包含“一键授权”“老黄历”“开机自启动”和“关于我们”。首次安装或从旧版升级后会自动打开一次；以后每次启动仍在后台检测，需要时可手动打开设置并点击刷新图标重新检测。已有锁屏密码不影响设置入口。

一键授权的适配范围为 Windows 10/11 x64，需要管理员批准且系统策略允许。其他版本或架构显示“暂未适配”，检测失败时显示具体错误。支持范围会固定显示在授权按钮上方，小窗口无需滚动即可找到按钮。点击“一键引导授权”后，由用户确认 Windows UAC；标准账户可能需要管理员凭据，取消后可重试。

授权会持续修改当前用户的系统入口限制，时钟解锁后仍保留。设置中的“恢复原有策略”可申请管理员授权恢复备份。显示“策略已配置”表示已读到五项策略值；部分策略需重新登录后生效，不代表完整 kiosk 安全保证。锁屏时设置入口隐藏，需先解锁。

“老黄历”菜单可关闭老黄历内容，也可分别控制右上角“时钟、秒表、倒计时、正计时”文字。默认进入时钟，默认隐藏“时钟”文字；取消某项只隐藏右上角文字，不会删除对应的计时功能。显示偏好会保存到本机。

“开机自启动”默认开启，登录 Windows 后自动打开程序；关闭后立即写入当前用户的启动设置。“关于我们”显示昆明迅琰网络科技有限公司、当前软件版本和检查更新入口。发现新版本后，程序会显示不能取消的更新提示，确认后下载并校验安装包，完成后自动重启。

## 保存与恢复

样式、背景、倒计时目标、显示偏好、开机自启动及窗口位置自动保存在电脑本地。打开程序始终先显示时钟。计时运行时打开时钟不会中断计时；关闭程序后不会在后台继续计时。

## 版本与平台

当前安装包面向 Windows 10/11 x64。壁纸当前使用静态图片，媒体层已经为后续动态壁纸预留。macOS 配置已包含在源码中，但需要在 macOS 构建与验证，当前交付不包含 Mac 安装包。私有 GitHub 仓库不能被普通客户端匿名访问，自动更新需要受控更新清单或认证代理。
