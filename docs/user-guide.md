# 使用说明

## 时钟

启动默认进入时钟，使用电脑当前本地时间与时区，显示时分秒、年月日、星期和本地黄历。黄历包括农历日期、干支日、生肖、节日或节气，以及今日宜忌。修改电脑时间后，显示会随之更新。

## 秒表与正计时

选择秒表或正计时后点击开始。暂停后可继续，重置归零。秒表显示百分之一秒。超过一小时会显示小时。

## 倒计时

选择倒计时，填写分钟和秒，再点击开始。最长 5999 分 59 秒；运行时无法修改目标时间。归零后显示“时间到”，点击重置可重新开始。当前版本没有到时声音。

## 显示与窗口

顶部调色盘可选择十四种样式，双列菜单包含经典五款，以及巨幕极简、星舰中枢、星尘聚时、电路脉冲、故障电压、酸性涂鸦、光速轨迹、三体星轨、光谱脉冲九款新增样式。切换样式不会中断正在运行的计时，关闭后会记住最后选择。右下角图片按钮选择背景或恢复该样式的原始背景。图钉按钮控制置顶；全屏按钮或 F11 适合投屏，Esc 退出全屏。

背景选择中提供二十张静态壁纸，可滚动浏览；新主题从“银河穹顶”开始，选择后自动保存，重新启动仍会使用。背景按比例居中覆盖，超宽屏和竖屏会裁切部分画面。新增十张原图实测 1672×941，在 4K、8K 屏幕上会放大，不能保证原生清晰度，详见 [壁纸说明](wallpapers.md)。

全屏时画面会铺满当前显示器，显示区不保留原生窗口的缩放边框。分辨率、系统缩放比例或显示器连接变化后会重新适配。顶部操作栏、模式导航和底部操作区平时隐藏，只有鼠标进入屏幕顶部热区后暂时显示。时钟、日期和黄历会根据屏幕尺寸自适应；布局支持 1080p、2K、4K 和 8K 视口，背景画质由原图像素与显示分辨率共同决定。

设置中的“窗口层级”分别控制未锁定和锁定时的全屏层级。置顶模式覆盖其他窗口；未锁定置底模式将时钟接入 Windows 桌面层，桌面图标、文件、任务栏和普通窗口显示在时钟上方。桌面空白处右键会打开 Windows 原生菜单，可使用刷新、新建等入口。置底模式不能同时遮挡其他窗口，也不能单独禁止桌面图标、任务管理器或系统快捷键；需要这些保护时，请使用锁定置顶模式并完成 Windows 锁屏保护授权。

未锁定置底全屏时，将鼠标移到未被其他窗口遮挡的屏幕顶部边缘，可调出独立工具栏。点击锁图标可上锁；点击返回窗口图标可退出桌面模式。选择设置、样式或壁纸时，会先返回普通窗口，再打开相应面板；桌面图标与空白处始终保留给 Windows 操作。

拖动标题栏移动窗口。鼠标移到四角出现斜向缩放光标，按住左键拖动，整个窗口保持 100:71 比例。窗口最小约 480×341，最大宽度 1600；不会超过当前显示器工作区域。全屏时居中显示并保持内容比例。

顶部锁图标用于设置和启用应用锁，密码为 4 至 16 位数字。设置密码后点击锁图标会进入 kiosk 全屏锁定，隐藏窗口按钮、模式切换、计时控制、背景选择、任务栏入口和缩放入口。Windows 版本在锁定期间启动原生键盘拦截，阻止普通按键、Win 键及常见系统快捷键。鼠标移动只会暂时显示顶部锁图标，锁按钮会与屏幕右边缘保持间距。点击锁图标打开密码框后，只接受数字、退格和回车；主数字区和小键盘均可输入，Num Lock 关闭时也会识别小键盘数字。输入正确密码并按回车解锁后，立即释放键盘拦截。

键盘保护启动失败时不会上锁；保护异常中断时会显示提示。主程序退出或失去心跳约 4 秒后自动释放拦截，避免程序异常时长期占用键盘。输入只在密码框打开时转交给该密码框，不保存按键记录。

该密码只保护 DAYAN桌面窗口，不是 Windows 系统登录密码。普通应用无法拦截 `Ctrl+Alt+Delete` 的系统安全桌面，也不能保证限制电源键、固件或其他受系统保护的入口。需要更严格的设备隔离时，应使用受支持 Windows 版本的系统键盘筛选器或专用 kiosk 配置；已有授权策略仍按设置页的说明持续生效。

## 设置与系统自检

点击顶部带齿轮图标的“设置”，菜单包含“一键授权”“显示设置”“开机自启动”“关于我们”和“窗口层级”。首次安装或从旧版升级后会自动打开一次；以后每次启动仍在后台检测，需要时可手动打开设置并点击刷新图标重新检测。已有锁屏密码不影响设置入口。

一键授权的适配范围为 Windows 10/11 x64，需要管理员批准且系统策略允许。其他版本或架构显示“暂未适配”，检测失败时显示具体错误。支持范围会固定显示在授权按钮上方，小窗口无需滚动即可找到按钮。点击“一键引导授权”后，由用户确认 Windows UAC；标准账户可能需要管理员凭据，取消后可重试。

授权会持续修改当前用户的系统入口限制，时钟解锁后仍保留。设置中的“恢复原有策略”可申请管理员授权恢复备份。Windows 10/11 Enterprise、Education 和 IoT Enterprise 可进一步配置 Keyboard Filter；需要重启时界面会提示，重启后回到此处继续授权。管理员筛选范围修改后需重新登录。家庭版和专业版显示“当前版本不支持”，管理员授权不能改变 Windows 版本授权。安全序列规则属于设备配置，在解锁后仍保留，恢复时还原应用保存的规则和设置，保留已安装的 Windows 组件。

“基础策略已配置”表示已读到五项策略值，“安全序列规则已配置”表示另外读到了 `Ctrl+Alt+Del` 规则和管理员筛选设置；两者都不替代实体设备验收。锁屏时设置入口隐藏，需先解锁。Windows 的维护恢复机制不被移除。

“显示设置”菜单可关闭黄历内容，也可分别控制右上角“时钟、秒表、倒计时、正计时”文字。默认进入时钟，默认隐藏“时钟”文字；取消某项只隐藏右上角文字，不会删除对应的计时功能。显示偏好会保存到本机。

“开机自启动”默认开启，登录 Windows 后自动打开程序；关闭后立即写入当前用户的启动设置。“关于我们”显示昆明迅琰网络科技有限公司、当前软件版本和检查更新入口。发现新版本后，程序会显示不能取消的更新提示，确认后下载并校验安装包，完成后自动重启。

## 保存与恢复

更新下载保留四路分段并行。遇到网络波动时会重试或切换下载线路，完整且校验通过的分段会保存在本机；重新点击更新或重开程序时自动续传。只有安装包最终 SHA-256 校验通过后才会执行安装，100% 表示完成校验。GitHub 的网络波动仍需发布方自有国内镜像来进一步改善。

样式、背景、倒计时目标、显示偏好、开机自启动及窗口位置自动保存在电脑本地。打开程序始终先显示时钟。计时运行时打开时钟不会中断计时；关闭程序后不会在后台继续计时。

## 版本与平台

当前安装包面向 Windows 10/11 x64。壁纸当前使用静态图片，媒体层已经为后续动态壁纸预留。macOS 配置已包含在源码中，但需要在 macOS 构建与验证，当前交付不包含 Mac 安装包。公开 GitHub Release 可作为普通客户端的默认更新源；自定义渠道可使用受控更新清单或认证代理。
