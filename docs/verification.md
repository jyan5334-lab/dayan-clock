## 1.6.7 锁定期间原生键盘拦截

验证日期：2026-10-29，Windows 11 x64。使用独立测试数据、测试密码与临时测试窗口，不修改本机系统策略或用户原有设置。

- 未锁定时原生按键能到达观察器和测试输入框；锁定后左右 Win、Win+R、Win+E、Win+S、Alt+Tab、Alt+F4、Ctrl+Esc、Ctrl+Shift+Esc、字母、Tab、Esc 和 F11 均未到达下游输入链。

- 移走隔离目录中的保护程序时，锁定请求返回失败，界面保持未锁定，键盘仍可用。测试完成后恢复原文件。
- 原生保护进程没有收到心跳时，在约 4 秒租期后退出，后续输入恢复；所属测试应用进程退出时，保护进程自动退出。
- 六组检查通过不等于所有物理键盘、权限级别和系统快捷键均已实机测试。没有注入 `Ctrl+Alt+Delete`，也没有注入会锁定当前用户会话的 Win+L；系统安全桌面、固件、电源及更高权限入口不属于普通应用的完整控制范围。

- `npm ci` 后执行 `npm run check`，确认版本、资源、文档和语法无误。
- 首次启动默认时钟，显示真实本地时间、年月日和黄历；设置能显示版本、架构与五项策略。
