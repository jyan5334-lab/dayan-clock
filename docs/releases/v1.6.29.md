# DAYAN桌面 1.6.29

## 动态背景全屏适配

- 修复“小狐无限闯关”在宽屏主显示器上使用固定比例 `contain` 时左右出现未覆盖区域的问题。
- 桌面适配层改为无裁切全视口填充，单屏、宽屏、竖屏和多屏逐显示器容器都能覆盖实际桌面范围。
- 显示器尺寸、方向或缩放变化后立即重绘 Canvas，避免切换分辨率时短暂出现空白。
- 原始闯关 HTML 和动画逻辑保持不变，桌面适配层仍隐藏音效、控制按钮、画面文字及进度条。

## 验证范围

- `npm run check`
- `npm run test:dynamic-backgrounds`
- 800×500、1920×1080、3440×1440、1080×1920 Canvas 覆盖、动画推进、边缘透明度和 resize 后重绘检查。
- 单屏与多屏动态背景逐显示器坐标布局检查。
