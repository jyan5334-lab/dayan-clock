# DAYAN桌面 1.6.0

本版本将产品显示名统一为 DAYAN桌面，并增加全屏窗口层级控制。

- 设置新增“窗口层级”，可分别配置未锁定和锁定时的置顶/置底模式。
- 未锁定置底模式覆盖当前显示器区域并调用 Windows 原生窗口排序放到桌面底部，适合桌面背景式展示。
- 置顶模式继续使用 Electron 全屏；锁定置顶模式继续使用 kiosk 全屏和系统策略授权。
- 全屏时顶部栏、模式导航和底部操作区默认隐藏，鼠标进入顶部热区后暂时显示。
- 关闭某个模式的显示后，该模式的文字、活动指示线和点击入口一并隐藏。
- 关于我们文案改为桌面展示、桌面保护与视觉美化工具，检查更新按钮居中。

Windows 10/11 x64。Windows 11 x64 为本次实机测试环境；Windows 10 尚未完成实机验收。置底模式依赖 Windows 窗口层级行为，其他窗口仍可能覆盖 DAYAN桌面；需要阻止桌面、任务管理器和系统快捷键时，应使用锁定置顶模式并完成 Windows 锁屏保护授权。

安装包未做 Windows 代码签名。升级前退出旧程序，运行 `DAYANClock-Setup-1.6.0-x64.exe`。用户设置、密码和系统策略不进入仓库。
