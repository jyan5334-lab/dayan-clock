# DAYAN桌面 1.6.5

发布日期：2026-10-29

## 修复内容

未锁定置底全屏时，旧版只是让普通应用显示在时钟上方，桌面图标仍被盖住，空白处右键也无法交给 Explorer。本版使用原生窗口辅助程序，将时钟接入真实桌面层，并让鼠标操作交回 Explorer。

- 桌面图标、文件、任务栏和普通应用位于时钟背景上方，可正常使用。
- 桌面右键使用 Windows 原生菜单，支持刷新、新建、显示设置等系统入口。
- 鼠标移到桌面顶部边缘显示操作栏，可上锁或返回普通窗口；设置、样式与壁纸配置在普通窗口中进行。
- 上锁前解除桌面挂接并恢复窗口输入，解锁后还原普通窗口大小。
- 保留四连接分段下载与 1.6.4 的安装交接及自动重启修复。

## 使用方式

在“设置 → 窗口层级”将“未锁定全屏”设为“置底”，再点击全屏。原有“置顶”选项继续用于覆盖桌面的展示场景。

## 验证与限制

Windows 11 x64 已验证实际 Explorer 图标层级、显示器物理尺寸、真实桌面右键菜单中的刷新及新建入口、顶部工具栏，以及锁定解锁和重复全屏切换。测试未创建或删除桌面文件，未修改用户锁屏策略；个人桌面截图及用户数据不发布到仓库。

Windows 10 的经典 WorkerW 路径尚未实机验收；第三方桌面增强程序或 Explorer 重启可能需要重新开启桌面模式。安装包未进行 Windows 代码签名。
