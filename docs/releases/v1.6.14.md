# DAYAN桌面 1.6.14

## 更新下载信息

- 进度条下方独立显示已下载大小、安装包总大小及百分比。
- 下一行显示实际下载状态（八路并行或回退四路）和实时速度。
- 增加更新说明、进度信息与按钮之间的间距；小窗口自动换行，内容过高时可以滚动。
- 准备安装时保留完整大小和 100% 进度，避免状态切换后数据消失。

本次调整下载窗口的显示，保留 1.6.13 的八路并发、四路回退、多源分段、断点续传和 SHA-256 校验。旧版本升级本次时仍使用旧版界面，安装 1.6.14 后生效。

当前工作区同时集成原创黑客动态壁纸：壁纸选择器增加“黑客动态”分组，包含矩阵绿、赛博青、琥珀、猩红和紫电五种配色。全屏窗口增加“当前显示器 / 全部显示器”选择，全部显示器按虚拟桌面范围铺开。
