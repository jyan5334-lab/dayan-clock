# DAYAN桌面 1.6.27

## 运行期间自动检查更新

- 保留启动后的自动检查，增加电脑本地时间每天 09:00、14:00、17:00 的检查。
- 休眠漏过的检查会在唤醒后合并补查一次；网络失败继续沿用重试和恢复联网后的检查。
- 有新版本时打开原有更新窗口，顶部图标、标题、版本号支持拖动，保留“现在更新”“今日不再提醒”“取消”。
- 普通取消后下个定时检查仍可提醒；今日暂停按本地日期生效，手动检查不受影响。
- 锁屏期间检查到新版本，解锁后再提示。

## 解锁保留全屏桌面

- 修复全屏锁定后解锁退回小窗口的问题。
- 解锁恢复上锁前的单屏或多屏范围，以及未锁定时的桌面层级；图标底层模式重新连接 Explorer 桌面。
- 上锁前是普通小窗口时仍返回原窗口；托盘“最小化（回到窗口）”行为保留。

## 验证范围

- Windows 本机打包程序回归：三个定时检查时段、取消与今日免提醒、原生窗口拖动、锁屏延后提示。
- 单屏及全部显示器范围：重复锁定和解锁，检查原生窗口尺寸、客户区和 Explorer 父窗口。
- 版本检查采用本地隔离更新源和受控时钟推进，未修改电脑系统时间，也未安装模拟版本。
