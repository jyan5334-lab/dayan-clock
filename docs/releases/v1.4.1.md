# DAYAN时钟 1.4.1

新生成的十张主题壁纸已加入实际程序，连同原有十张共二十张。点击右下角图片按钮，滚动背景列表即可选择；关闭重开后保留选择。十四款显示样式及四种计时模式继续可用。

- 新主题：银河穹顶、钛银机库、深海遗迹、极夜雪境、翡翠秘境、玫瑰星纱、月下花庭、流光琉璃、金曜沙海、雨夜霓城。
- 原始 PNG 随软件离线打包，源码包括图片、生成提示词、尺寸清单和 SHA-256。
- 壁纸面板增加滚动与高度限制，最小窗口中也可访问末尾主题。
- README 提供十款图文介绍，更新记录、使用说明与部署说明同步更新；维护文档补充每次推送的介绍和变更说明要求。

验收已通过：源码检查确认版本、20 张壁纸、路径、PNG 签名和 SHA-256；打包程序确认小窗口滚动、壁纸切换、计时不中断、全屏锁屏、密码解锁和重启持久化；完整桌面回归确认四角缩放、14 种样式、四种计时模式、全屏标题栏自动隐藏和状态恢复。验证使用独立数据目录，没有修改现有用户设置或 Windows 策略。详细记录见 `docs/verification.md`。

新增图片实测均为 **1672×941**，未放大或重采样，不属于原生 4K / 8K 壁纸；全屏布局适配不保证图片达到显示器的原生清晰度。画质限制和验收范围见仓库 `docs/wallpapers.md`、`docs/verification.md`。

Windows 10/11 x64。Windows 11 x64 为本次实机测试环境，Windows 10 尚未实机验收；安装包未做 Windows 代码签名。本次不更改用户现有 Windows 策略。

升级前退出旧程序，运行 `DAYANClock-Setup-1.4.1-x64.exe`。设置页可核对软件版本。源码为 `DAYANClock-Source-1.4.1.zip`，校验文件为 `SHA256SUMS-1.4.1.txt`；用户设置与密码不进入仓库。
