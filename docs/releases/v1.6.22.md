# DAYAN桌面 1.6.22

## 原创动态背景

背景选择器新增“动态背景”分类，包含“鹈鹕骑行”和“海边日落骑行”。
原版 SVG 和动画脚本不作修改，保留默认运动速度、颜色和场景元素；桌面适配层隐藏演示页标题和按钮，保持画面比例。素材全部打包在本地，断网可用。

多屏桌面按系统提供的显示器位置分别适配动画，时间、日期、农历和老黄历继续只在主屏显示。

## 桌面层级修复

- 修正开机参数启动后，普通 show 操作将桌面壁纸提升到图标上方的行为。
- 新版 Windows 的 Progman 桌面采用无重定向合成，壁纸对应启用不透明分层窗口；保持图标在最上方、系统壁纸 WorkerW 在最下方。
- 校正尺寸时不再反复重算非客户区。
- 托盘回归新增 NotifyIcon 自身的菜单调用链，不再仅依赖普通窗口 Menu.popup。
- 未锁定置底模式使用无边框桌面子窗口，退出 Windows 原生全屏状态，并持续维护客户区完整边界与图标顺序，针对主屏托盘裁切问题调整。

## 主屏解锁与开机启动

- 解锁按钮放到主屏黄历下方，显示“小锁＋点击解锁”，无需寻找多屏最右上角。
- 密码框按主屏居中，提供屏内数字键盘和系统键盘入口；物理数字键、小键盘、删除和回车不依赖系统授权及瞬时窗口焦点。
- 全部样式使用主屏内容区域，光环时间保持在圆环内部，日期和黄历向上收拢。
- 安装版优先使用当前用户登录任务启动，配置失败时保留原启动项；不保存用户密码，不调整系统全局启动延迟。关闭自启动和卸载时清理任务。
- 登录启动时对 Explorer 尚未就绪的情况进行短暂重试；保存界面就绪与桌面呈现耗时，便于区分系统登录等待和程序实际加载时间。

## 验证范围

原始文件 SHA-256、固定时刻逐帧 SVG 对比、动画前进、横屏/超宽屏/竖屏比例、实际 Electron 选择与保存、多屏背景坐标均覆盖。
桌面回归通过开机启动参数，在当前显示器范围和全部显示器范围分别检查原生窗口图标顺序、合成标志、完整客户区及托盘菜单开关；通过实际屏幕像素检查下半屏壁纸仍然显示。
未主动重启用户电脑；真实注销或冷启动后的最终表现仍需设备验收。

本次源码运行版的真实数字键、小键盘、退格、回车及普通快捷键拦截回归通过；打包版通过 42 项样式与主屏解锁布局检查、托盘锁定/解锁流程和包内文件一致性核对。打包版真实输入探针被 Windows 前台焦点限制阻断，未把该项报告为通过。登录任务的创建与删除已实测，未进行真实关机重启验收。

安装包未进行 Windows 代码签名。系统安全桌面、设备电源及固件入口不属于普通应用键盘拦截范围。
