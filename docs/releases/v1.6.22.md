# DAYAN桌面 1.6.22

## 原创动态背景

背景选择器新增“动态背景”分类，包含“鹈鹕骑行”和“海边日落骑行”。
原版 SVG 和动画脚本不作修改，保留默认运动速度、颜色和场景元素；桌面适配层隐藏演示页标题和按钮，保持画面比例。素材全部打包在本地，断网可用。

多屏桌面按系统提供的显示器位置分别适配动画，时间、日期、农历和老黄历继续只在主屏显示。

## 桌面层级修复

- 修正开机参数启动后，普通 show 操作将桌面壁纸提升到图标上方的行为。
- 新版 Windows 的 Progman 桌面采用无重定向合成，壁纸对应启用不透明分层窗口；保持图标在最上方、系统壁纸 WorkerW 在最下方。
- 校正尺寸时不再反复重算非客户区。
- 托盘回归新增 NotifyIcon 自身的菜单调用链，不再仅依赖普通窗口 Menu.popup。

## 验证范围

原始文件 SHA-256、固定时刻逐帧 SVG 对比、动画前进、横屏/超宽屏/竖屏比例、实际 Electron 选择与保存、多屏背景坐标均覆盖。
桌面回归通过开机启动参数，在当前显示器范围和全部显示器范围分别检查原生窗口图标顺序、合成标志、完整客户区及托盘菜单开关；通过实际屏幕像素检查下半屏壁纸仍然显示。
未主动重启用户电脑；真实注销或冷启动后的最终表现仍需设备验收。
