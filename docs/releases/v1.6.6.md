# DAYAN桌面 1.6.6

发布日期：2026-10-29

## 修复内容

修复未锁定置底全屏后左右两侧的小条空白。旧版虽然将窗口外框扩展到显示器边界，但 Chromium 仍按普通窗口预留缩放边框：当前机器复现为 3440×1440 的外框，实际壁纸区只有 3426×1433。

本版先让窗口进入真正的全屏状态，再挂接到桌面图标层下方，使壁纸客户区与显示器四边完全重合。普通窗口继续支持四角等比例缩放。

- 根据当前显示器尺寸及系统缩放换算物理坐标。
- 分辨率、缩放比例或显示器连接变化后重新适配。
- 保留桌面图标、文件、任务栏与原生右键菜单的正常操作。
- 保留锁定解锁、顶部边缘工具栏及现有四连接分段高速下载。

## 验证与限制

Windows 11 x64 开发模式和最终打包程序已验证 3440×1440、1920×1080 两台实体显示器的客户区与页面边界；1080p、1440p、4K、8K 和 1080×1920 竖屏通过分辨率变化模拟验证，不代表已在所有这些规格的实体显示器上验收。十组完整桌面回归和安装包负载校验通过，详见 [验证记录](../verification.md)。

Windows 10 经典 WorkerW 分支尚未实机验收；第三方桌面增强程序或 Explorer 重启可能需要重新开启桌面模式。安装包未进行 Windows 代码签名。

## 下载与升级

- Windows x64 安装包：`DAYANClock-Setup-1.6.6-x64.exe`。
- 源码与本地素材：`DAYANClock-Source-1.6.6.zip`。
- 文件校验清单：`SHA256SUMS-1.6.6.txt`。

支持应用内检查更新。手动升级时先退出旧程序，再运行安装包，完成后在“设置 → 关于我们”确认版本为 1.6.6。升级保留本机设置，用户数据、密码和系统策略备份不进入仓库。
