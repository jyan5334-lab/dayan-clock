# DAYAN桌面 1.6.12

## 修复原有策略恢复

- 修复点击“恢复原有策略”后出现 `Windows 策略: Invalid policy backup.`、快捷键限制未撤销的问题。
- 同时兼容 `Registry::HKEY_USERS` 与旧版 `HKCU` 备份，先验证备份所属用户和五项原值，再执行恢复。
- 恢复后重新读取 Windows 策略值，确认与授权前一致才提示成功。未完成的项目保留备份，支持再次恢复。
- 旧版备份只迁移一次，防止恢复后再次导入，导致按钮和状态错误。
- 完成后设置页显示“已恢复原有策略”，授权按钮变为“重新授权”；安装前已有的限制会保留并明确标记。
- 恢复记录保存在本机，重开软件后继续验证；不上传用户策略、密码或个人设置。

## 使用方法

安装新版后，在“设置 → 一键授权”中点击“恢复原有策略”，同意 Windows 管理员确认。程序自动复检并展示结果。部分 Windows 快捷键需要保存工作、注销并重新登录后恢复。

如提示原有配置仍有限制，表示该限制在 DAYAN 授权前已存在；本程序不会删除其他软件或组织配置的策略。

## 兼容与验证

Windows x64。覆盖原路径错误、旧版备份迁移、原有数值保留、备份损坏、权限不足、写入后复检失败和分项恢复后重试。保留现有四连接并行更新下载方案。
