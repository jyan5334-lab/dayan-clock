# DAYAN时钟 1.5.0

本版本优化设置页面并增加显示、启动和更新相关功能。

- 设置改为四项菜单：一键授权、老黄历、开机自启动、关于我们。
- 老黄历菜单可控制黄历内容及右上角“时钟、秒表、倒计时、正计时”文字；默认进入时钟，默认隐藏“时钟”文字。
- 日期增加星期显示。
- 安装后默认开启开机自启动，用户可在设置中关闭并保存当前状态。
- 关于我们标注昆明迅琰网络科技有限公司，显示当前版本并提供手动检查更新入口。
- 启动时自动检查更新；发现更高版本后显示不可取消的确认更新提示，下载后校验并重启安装。

本次已通过源码检查、开发模式完整桌面回归、Windows `win-unpacked` 回归、20 张壁纸专项回归和本地模拟更新清单验收。详细记录见 `docs/verification.md`。

Windows 10/11 x64。Windows 11 x64 为本次实机测试环境，Windows 10 尚未实机验收；安装包未做 Windows 代码签名。本次不更改用户现有 Windows 策略。

仓库已于 2026-10-28 切换为 Public，普通客户端可以匿名读取 GitHub Release，默认自动更新源可直接使用。需要自定义发布渠道时，可让 `DAYAN_UPDATE_MANIFEST_URL` 指向受控清单和下载代理；不要把 GitHub Token 写入安装包。

升级前退出旧程序，运行 `DAYANClock-Setup-1.5.0-x64.exe`。源码为 `DAYANClock-Source-1.5.0.zip`，校验文件为 `SHA256SUMS-1.5.0.txt`；用户设置、密码和系统策略不进入仓库。
