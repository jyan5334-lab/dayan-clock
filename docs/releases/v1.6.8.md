# DAYAN桌面 1.6.8

发布日期：2026-10-29

## 系统级锁屏授权

设置中的“一键引导授权”现在会先配置当前 Windows 用户的策略，并尝试检测和启用 Windows Keyboard Filter。只有 Windows 10/11 Enterprise、Education 或 IoT 版本提供 `Client-KeyboardFilter` 时，才会显示 Ctrl+Alt+Delete 系统安全序列已配置。

该步骤需要管理员批准。Keyboard Filter 的系统设置作用于当前设备，会持续到恢复原有策略；如果系统版本没有该组件，软件会保留基础策略并明确显示为“基础策略已配置”，不会伪装成完整防护。

首次开启组件会先保存备份，并提示重启电脑；重启后继续授权才能配置规则。修改管理员筛选范围后需要重新登录。恢复时还原应用首次授权前保存的规则、管理员筛选设置和用户策略，保留 Windows 已安装组件。Windows 的维护恢复机制保持可用。建议使用独立展示账户。

## 更新下载

更新请求探测原有直连与遵循 Windows 代理/PAC 的 Chromium 通道。先选择可用线路，再保持四路、2 MB 分段下载；保留 API 和浏览器下载入口，支持发布方清单中的可信镜像。网络波动时重试缺失分段，切换线路不删除已完成进度；重新打开程序仍会校验并复用完整分段。界面显示传输速度，只有完整文件校验通过才显示 100%。

正常线路仍使用 2 MB 请求；遇到大响应卡住、超时或中断时自动降到 256 KB，仍受限时再降到 64 KB，在四个工作连接中组合为可续传的完整分段。不会为了兼容较差线路而固定降低所有用户的请求大小。

启动检查同时支持 GitHub API 与 Release 的 `update.json`，减少单一入口故障的影响。没有内置不明第三方代理、访问令牌或关闭 TLS 校验。跨境网络的长期稳定速度仍需发布方部署国内对象存储/CDN；当前未凭空添加未部署的镜像地址。

下载完成仍必须通过 SHA-256 校验，校验成功后才交给独立安装辅助程序，安装完成后核对版本并重启 DAYAN桌面。

## 边界

本机为 Windows 11 专业版，因此本次只完成了系统授权流程的模拟验证，未在支持版本上验证实体键盘的安全序列拦截。真实 GitHub 大文件下载在当前网络仍有超时；本地下载、断点续传和打包版网络通道检查通过，不代表中国网络下始终高速。详细范围见 [桌面验收](../verification.md)。

普通应用内的低层键盘保护继续负责锁屏期间的 Win 键和常见组合键。Ctrl+Alt+Delete 只能由受支持的 Windows Keyboard Filter 或受管 kiosk 配置处理；Windows 家庭版、专业版及未提供该组件的系统不能通过普通应用权限获得同等能力。
