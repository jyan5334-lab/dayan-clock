# DAYAN桌面 1.6.17

## 多屏主屏布局

- “全部显示器”模式下继续使用 Windows 虚拟桌面范围铺设背景。
- 读取 Windows 主显示器边界，将时间、日期、农历和黄历统一放在主屏的居中靠上区域。
- 副屏只显示所选背景，不重复渲染时钟、日期和黄历，避免内容出现在两块屏幕中间。
- 屏幕排列、分辨率、系统缩放比例变化后重新计算虚拟桌面和主屏坐标。

## 多屏锁屏

- 锁屏时覆盖整个虚拟桌面，副屏同步进入锁定覆盖状态。
- 多屏锁屏不再使用 Windows 单显示器 kiosk 的范围限制，仍保留无边框、置顶、跳过任务栏和键盘保护。
- 不同时间样式、日期和黄历组件共用主屏定位规则。

## 验证

- 在真实双显示器环境验证虚拟桌面边界覆盖，锁屏窗口覆盖整个联合区域。
- 模拟主屏布局后验证时间显示区限制在主屏宽度内，页面无脚本错误。
- 源代码检查和 `git diff --check` 通过。
