# DAYAN桌面 1.6.9

发布日期：2026-10-30

## 修复模拟更新提示

上一轮本地下载验收使用 9.9.9 作为模拟版本。测试运行的是独立数据目录中的程序，但窗口外观没有明确区分，可能被误认为正式更新。9.9.9 没有发布到 GitHub Release，也没有保存在用户正式配置中。

本次将模拟更新限制为专用启动参数、独立测试数据和本机回环 HTTP 服务同时存在时才启用。普通启动不读取 `DAYAN_TEST_UPDATE_URL`；测试数据不能与正式用户目录重叠。更新测试窗口默认隐藏且不进入任务栏，即使查看其界面也会明确显示“本地更新测试”，按钮禁用，主进程安装接口再次拒绝模拟更新。

测试结束后关闭所属测试进程，测试截图只保存在忽略的工作目录，不覆盖正式产品截图。本次不调整四路并行下载、断点续传、安装重启或系统授权实现。

## 验证范围

通过更新来源隔离检查及开发模式、最终 Windows 打包版的本地网络验收，检查隐藏窗口、模拟更新禁止安装、清单读取、直连与系统网络通道下载和 SHA-256 校验。详细结果见 [桌面验收](../verification.md)。本地验证不代表真实 GitHub 网络速度，Keyboard Filter 的系统版本限制仍与 1.6.8 相同。
