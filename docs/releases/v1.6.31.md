# DAYAN桌面 1.6.31

- 显示器顺序或尺寸变化复用现有背景媒体；全屏忽略仅任务栏可用工作区变化的通知，减少背景重建和桌面窗口重绘。
- 加入有大小上限的本地渲染诊断，供长期偶发白闪定位；短时验收不代表该现象已被完全消除。

- 自动更新改为后台流程：启动、联网恢复以及每天 09:00、14:00、17:00 检查新版本，下载、校验后静默安装，不再自动弹出更新窗口。
- 更新重启先恢复原来的桌面背景、时钟样式、全屏范围和显示器，再显示窗口；修复升级后退回小窗口的问题，并兼容旧版首次升级。
- 单屏、多屏全屏及桌面图标上方/下方的显示设置均保持；更新前是普通窗口或最小化状态时，也按原状态恢复。
- 应用锁屏或 Windows 系统锁定期间推迟安装，解锁后继续；安装交接中检测到锁定会取消交接，继续运行当前桌面。
- 安装辅助程序未就绪时保持原程序运行；安装失败保留安装包及日志，并尝试恢复原来的桌面。
- 保留八路分段下载、限流回退四路、断点续传及最终 SHA-256 校验。设置中的手动检查仍可查看日志和下载进度。

应用更新需要短暂重启，受保护安装目录可能仍需 Windows 授权。后台更新从安装此版本后生效。

- 新增“海岛骑行 · 昼夜相伴”3D 动态背景：原版场景离线打包，日夜随本地时间变化，每 3–5 分钟平滑切换机位，配合挥手、短暂慢动作及早中晚夜问候。
- 新场景无声音和演示控件，不拦截桌面点击；单屏、多屏及竖屏分别适配，问候只在主屏展示。
