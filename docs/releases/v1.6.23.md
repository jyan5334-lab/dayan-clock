# DAYAN桌面 1.6.23

## 动态背景全屏适配

- 修复鹈鹕骑行、海边日落骑行在宽屏显示时两侧留白的问题。
- 根据每块显示器的实际宽高等比例铺满，适配普通横屏、超宽屏、竖屏及多屏混合布局；超出屏幕的边缘居中裁切，不拉伸动画。
- 原始动画文件、SVG 和脚本保持不变，播放速度不变；调整尺寸不重新加载动画。

## 统一背景规则

- 静态图片、视频和网页动画都按每块显示器独立铺设，避免按整个虚拟桌面居中缩放。
- 时间、日期、农历和黄历仍只在主屏显示。
- 项目记录新增背景接入规范，后续背景必须优先满足单屏、多屏全屏覆盖和不同屏幕比例验收。

## 验证

- 比较原始动画与嵌入动画固定时刻的完整 SVG，检查动画持续播放及选择保存。
- 检查 4:3、16:9、16:10、21:9、32:9、竖屏的真实绘制范围及截图边缘像素。
- 使用模拟系统布局检查混合分辨率、不同缩放比例、负坐标副屏及热切换；模拟布局不等同于所有实体多屏设备实测。
