# DAYAN时钟 1.3.1

面向培训、直播和屏保展示的离线桌面时钟。本版本包含时钟、秒表、倒计时、正计时，五种数字样式、十张本地壁纸和本地黄历。

## 本次更新

- 顶部独立“设置”入口，已有锁屏密码时仍可打开系统与授权设置。
- 安装或升级后首次启动展示系统自检，每次启动检测 Windows 版本、架构和五项策略。
- 小窗口设置支持滚动，兼容范围与“一键引导授权”按钮固定可见。
- 授权取消可重试，增加策略恢复入口，保留首次策略备份，支持空格与中文路径。
- 补充私有仓库图文介绍、部署要求、源码检查和换电脑维护说明。

## 下载

- `DAYANClock-Setup-1.3.1-x64.exe`：Windows x64 安装包。
- `DAYANClock-Source-1.3.1.zip`：从本版本 Git 标签导出的完整仓库源码，含图片与文档，不含依赖和个人设置。
- `SHA256SUMS-1.3.1.txt`：安装包与源码包的 SHA-256 校验清单。

Windows 10/11 x64 为安装包目标范围；已实机验证 Windows 11 专业版 x64。普通使用不需要 Node.js 或管理员权限。安装包当前未做代码签名，可能显示未知发布者。

## 验证与限制

已有桌面验收覆盖开发模式、打包程序及安装包中的实际程序，包括十张壁纸、五种样式、四种模式、全屏、应用锁、窗口缩放、单实例及设置保存。设置流程另验证了真实系统只读检测与模拟授权分支，详见仓库 `docs/verification.md`。

系统策略写入与恢复尚未完成实际管理员授权验收。策略在解锁和退出后持续存在，可在设置中恢复；部分策略需重新登录。`Ctrl+Alt+Delete` 安全界面本身不能被普通桌面程序拦截。Windows 10 未实机验收，未来 Windows 版本、ARM64 与 macOS 尚未验证，当前不提供 Mac 安装包。

本仓库及 Release 均仅向有权限的账号提供访问。个人配置、密码记录、系统策略备份不随源码上传。
