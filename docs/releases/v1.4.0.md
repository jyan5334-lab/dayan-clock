# DAYAN时钟 1.4.0

本次新增预览中标记的九款样式，连同原有五款共十四款，均可在顶部调色盘中选择。

- 巨幕极简、星舰中枢、星尘聚时。
- 赛博：电路脉冲。
- 朋克：故障电压、酸性涂鸦。
- 科幻：光速轨迹、三体星轨、光谱脉冲。

新增样式共用已有计时状态，可切换时钟、秒表、倒计时与正计时，保留十张壁纸、日期与黄历，以及全屏和密码锁定。升级后保留原有设置。

Windows 10/11 x64。Windows 11 x64 为实机测试环境，Windows 10 尚未实机验收；当前安装包未做 Windows 代码签名。

下载 `DAYANClock-Setup-1.4.0-x64.exe` 安装；源码为 `DAYANClock-Source-1.4.0.zip`，校验文件为 `SHA256SUMS-1.4.0.txt`。升级前退出旧程序，在设置页可核对软件版本。
