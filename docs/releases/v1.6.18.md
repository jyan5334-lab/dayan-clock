# DAYAN桌面 1.6.18

## 系统托盘与桌面恢复

- 全屏桌面模式常驻 Windows 系统托盘，右键菜单提供“设置”“切换样式”“切换背景”“最小化（回到窗口）”和“退出”。
- “设置”打开现有设置页；切换样式和背景复用现有选择器；最小化退出全屏并恢复上次普通窗口尺寸；退出关闭程序。
- 锁屏期间托盘菜单全部禁用，只有解锁后才能继续使用这些入口。
- 开机自启动默认开启，Windows 登录启动时自动恢复最近一次保存的样式、背景和全屏桌面状态。
