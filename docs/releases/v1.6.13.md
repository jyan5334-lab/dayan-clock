# DAYAN桌面 1.6.13

## 下载速度优化

- 更新下载使用 8 个并发分段连接，最多合并 10 个可信 HTTPS 地址。
- 超时、网络错误或服务器限流时退回 4 路；遵守服务器的重试等待时间，避开暂时失败的地址。
- 分段会在探测通过的 GitHub 和发布方配置的 `mirrorUrls` 之间分配，复用跳转后的下载地址；稍晚响应的健康通道也能加入下载池。
- API 和更新清单只在版本、文件大小及 SHA-256 一致时合并地址，避免混入其他版本。
- 保留断点续传、已完成分段复用、分段校验和最终 SHA-256 校验。

8 路是默认上限。继续增加连接数不一定更快，因此程序只使用更新清单中真实可访问的地址，不会自动加入未知下载代理。目前发布清单尚未配置独立的国内 CDN；GitHub 的 API 与浏览器入口可能最终到达同一下载域名，不能视为多份独立带宽。中国网络的稳定速度仍取决于实际链路；发布方接入自己控制的国内镜像后可参与合并下载。

## 验证与升级

- 通过 19 项下载检查，覆盖多源合并、晚到通道加入、第十个地址、失败换线、429 等待及降级、断点续传、错误文件拦截。
- 打包后使用本地测试服务验证实际 8 路并发；20 MB 文件分别经过直连及 Windows 系统网络通道，摘要核对一致。该结果验证程序行为，不代表中国各网络的实际下载速度。
- 使用模拟安装器的安装交接检查覆盖正常完成、旧进程自然退出、安装失败、版本不符及安装包缺失，确认原有重启和失败保留逻辑；这不等同于真实电脑上的安装验收。
- 新下载机制从 1.6.13 起生效；仍使用旧版本的电脑，升级本次时运行的仍是旧下载器，也可直接运行新版安装包。
