# DAYAN桌面 1.6.26

## 桌面菜单与预览

- 设置各页高度统一，内容从顶部显示，长内容在窗口内滚动。
- 全屏下的设置、样式、背景及锁屏管理窗口可通过标题栏拖动；切换菜单保留移动后的位置。
- 样式和背景选中后立即应用，窗口保持打开，可连续预览，点击右上角关闭。
- 单屏及多屏的桌面背景继续全屏运行；最小化保留回到小窗口的行为。

## 托盘锁屏管理

- 新增“锁屏”菜单，提供立即锁屏、锁屏快捷键和修改密码。
- 快捷键保存后全局生效，重启恢复；冲突时提示更换，不覆盖原设置，支持清空停用。
- 支持原密码验证后输入两次新密码，或回答原先保存的密保问题后重置密码。
- 首次使用仍需设置数字密码和密保；全部验证数据仅保存在本机。
