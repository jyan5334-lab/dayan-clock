# DAYAN桌面 1.6.3

发布日期：2026-10-29

## 本次更新

- 修复未锁定置底全屏时桌面图标和文件被时钟窗口遮挡的问题。
- 置底窗口接入 Windows 桌面 WorkerW 层，任务栏和桌面图标保持在时钟上方。
- 原生窗口层级调整改为异步执行，修复从小窗口点击全屏时约 2 至 3 秒的卡顿。
- 设置菜单将“老黄历”改为“显示设置”，并更换为滑杆设置图标。

## 验证范围

- `npm run check` 通过。
- 开发模式与打包程序桌面回归通过。
- Windows 11 x64 当前环境完成置底窗口和全屏切换验证。

## 已知限制

WorkerW 桌面层属于 Windows 桌面行为，第三方桌面增强软件、虚拟桌面或多显示器特殊布局可能改变窗口层级表现。
