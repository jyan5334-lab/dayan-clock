# DAYAN时钟 1.3.2

修复退出全屏或锁屏后恢复窗口时，两侧出现大块黑边的问题。

## 修复内容

- 进入锁屏前单独保存普通窗口尺寸和位置，屏幕大小不再覆盖普通窗口记录。
- 解锁、退出全屏与最小化恢复时，恢复并校正普通窗口尺寸；全屏最小化恢复后保持全屏展示。
- 页面背景和标题栏填满实际窗口客户区，数字保持统一比例缩放。

## 下载与升级

- `DAYANClock-Setup-1.3.2-x64.exe`：Windows 10/11 x64 安装包。
- `DAYANClock-Source-1.3.2.zip`：本版本完整源码、图片与文档。
- `SHA256SUMS-1.3.2.txt`：安装包和源码包校验值。

退出旧版后运行安装包升级。原有样式、背景、密码和本机设置保留。安装包当前未做代码签名。当前不提供已验证的 Mac 安装包。

## 验证

在 Windows 11 x64 的独立测试用户数据目录验证锁屏解锁、连续三次全屏切换及全屏最小化恢复、普通窗口最小化恢复。普通窗口恢复到原位置与尺寸，页面边缘与窗口客户区一致。

完整计时与设置回归结果见仓库 `docs/verification.md`。本次验证不修改本机 Windows 策略。
