# DAYAN桌面 1.6.28

## 动态背景修复

- 修复“傍晚风格的鹈鹕骑车”在动态背景选择器中无法正常选中的问题。
- 动态背景选择后立即保持预览，当前可见样式只创建需要的动画 iframe。
- 隐藏样式不再加载和运行动态背景，减少多套样式同时运行造成的卡顿。
- 保留原始鹈鹕动画文件、SVG、脚本、颜色和播放速度。

## 多屏托盘工具栏

- 托盘悬浮工具栏只在系统主屏右上角显示。
- 鼠标移动到副屏时自动隐藏工具栏，副屏继续只显示桌面背景。
- 移除工具栏边框线，避免副屏边缘出现不需要的线条。

## 小狐无限闯关动态背景

- 新增“小狐无限闯关”动态背景，原始 HTML 文件按字节保存在动态背景原始资源目录。
- 通过适配层隐藏音效、暂停、重新开始按钮、Canvas 文字和底部关卡进度条，仅保留像素风格的闯关画面。
- 通关或失败后自动重新开始，作为桌面背景持续循环运行。
- 适配横屏、宽屏和竖屏显示范围，画布完整覆盖桌面区域。

## 验证范围

- `npm run check`
- 单屏和多屏动态背景覆盖、主体完整性及多显示器坐标检查。
- Electron 实际点击“傍晚风格的鹈鹕骑车”，确认选中状态、资源地址和隐藏样式 iframe 数量。
- 托盘锁屏菜单、设置、样式及背景菜单回归测试。
- 小狐动态背景控件隐藏、文字隐藏、循环推进和不同屏幕尺寸覆盖检查。
