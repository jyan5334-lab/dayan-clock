# DAYAN桌面 1.6.1

发布日期：2026-10-28

## 本次更新

- GitHub Release 更新下载优先使用资产 API 地址，减少浏览器下载地址跳转带来的等待。
- 下载失败时自动尝试更新清单提供的 `mirrorUrls` 和原始下载地址。
- 更新弹窗增加“正在连接下载服务器”“已连接，正在下载更新”等状态提示。
- 增加连接和分段接收超时，避免网络异常时长时间停留在“正在准备更新”。
- 将 `fetch failed` 等网络错误转换为中文说明，并提示配置可访问的镜像更新源。

## 下载文件

- `DAYANClock-Setup-1.6.1-x64.exe`
- `DAYANClock-Source-1.6.1.zip`
- `SHA256SUMS-1.6.1.txt`

## 验证范围

- Windows x64 安装包构建成功，安装器未签名。
- 开发模式和打包模式的更新清单模拟通过。
- 打包程序完整桌面回归通过：窗口层级、全屏热区、锁屏、设置、壁纸和计时功能均通过。
- 当前环境对 GitHub Release API 和资产 API 的网络探测通过；中国网络运营商的实际下载速度可能不同。

## 已知限制

GitHub Release 资产仍可能受到当地网络、运营商路由或下载域名策略影响。若用户无法稳定访问 GitHub 下载域名，应将安装包同步到可访问的对象存储或 CDN，并在自定义更新清单中配置 `mirrorUrls`。
