# DAYAN桌面 1.6.7

发布日期：2026-10-29

## 修复内容

修复锁定时按 Windows 键仍弹出开始菜单的问题。此前只在应用窗口内过滤键盘事件，本版增加仅在锁定期间运行的原生低层键盘保护进程。

- 密码框关闭时拦截普通按键和常见系统快捷键；打开后仅接受数字、退格和回车。
- 支持主数字区、小键盘及 Num Lock 关闭时的小键盘数字输入。
- 数字输入直接转交密码框，不保存按键记录；错误密码保持锁定，正确密码解锁并移除拦截。
- 保护进程启动失败时拒绝上锁；主程序退出、界面无响应或心跳中断时释放拦截。
- 保留全屏边界修复和现有四连接分段高速下载。

## 范围与限制

Windows 11 x64 开发模式和最终打包程序均使用 Windows 原生输入验证左右 Win、Win+R/E/S、Alt+Tab/F4、Ctrl+Esc、Ctrl+Shift+Esc，以及普通按键、密码输入和异常释放。完整桌面回归与安装包负载校验通过，详见 [验证记录](../verification.md)。

普通桌面应用不能屏蔽 `Ctrl+Alt+Delete` 的系统安全桌面，也不能保证屏蔽电源、固件或所有权限级别的系统入口。完整设备限制需要受支持 Windows 版本的系统键盘筛选器或专用 kiosk 配置。Windows 10、其他系统架构及物理键盘型号尚未逐一实机验收。安装包未进行 Windows 代码签名。

## 下载与升级

- 安装包：`DAYANClock-Setup-1.6.7-x64.exe`。
- 源码：`DAYANClock-Source-1.6.7.zip`。
- 校验清单：`SHA256SUMS-1.6.7.txt`。

可在应用内检查更新，或退出旧程序后手动安装。完成后在“设置 → 关于我们”确认版本为 1.6.7，再测试锁定和解锁。升级保留本机设置，用户密码与系统策略备份不进入仓库。
