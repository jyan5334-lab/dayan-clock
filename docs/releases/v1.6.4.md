# DAYAN桌面 1.6.4

发布日期：2026-10-29

## 本次修复

更新包下载完成后，旧程序可能退出而没有进入安装。本版本修正 PowerShell 安装辅助进程的启动方式，等待其就绪后才退出旧程序；待旧进程结束后打开安装程序，安装结束后核对版本并重新启动。

- 保留现有四连接、2 MB 分段并行下载，下载提速策略保持不变。
- 更新安装显示进度；安装失败保留安装包和日志，提示手动继续安装，并尝试重新打开应用。
- 安装日志保存在用户数据目录的 `updates/<任务编号>/install.log` 与 `helper-output.log`。

## 旧版升级

1.6.2 / 1.6.3 客户端仍使用旧的安装交接代码。若下载完成后直接关闭，请手动运行本版安装包一次，之后更新使用修复后的流程。用户设置、数字密码与 Windows 授权策略继续保留。

安装包未进行 Windows 代码签名，系统可能提示未知发布者。

## 验证

Windows 11 x64 通过五组安装交接及失败恢复测试，并使用实际 NSIS 安装包完成本机 1.6.2 → 1.6.4 覆盖升级与重启验证，真实用户配置保持不变。实际安装回归使用静默参数；产品更新默认显示安装界面。源码检查及打包程序更新提示回归通过。
