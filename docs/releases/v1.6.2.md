# DAYAN桌面 1.6.2

发布日期：2026-10-28

## 本次更新

- 安装包优先使用最多 4 条连接并行分段下载，减少单连接限速造成的等待。
- 每个分段自动重试，并校验 HTTP Range 范围和分段长度。
- 镜像或下载服务器不支持分段时自动退回普通下载。
- 下载完成后继续执行完整 SHA-256 校验，校验通过才启动安装。

## 下载文件

- `DAYANClock-Setup-1.6.2-x64.exe`
- `DAYANClock-Source-1.6.2.zip`
- `SHA256SUMS-1.6.2.txt`

## 验证范围

- Windows x64 安装包构建成功，安装器未签名。
- 开发模式和打包模式的更新清单模拟通过。
- 打包程序完整桌面回归通过：窗口层级、全屏热区、锁屏、设置、壁纸和计时功能均通过。
- GitHub Release 资产支持分段请求时启用并行下载；不支持或响应超时时自动退回普通下载。

## 已知限制

并行连接只能改善可访问下载服务器的吞吐。如果当地网络完全无法访问 GitHub 下载域名，仍需在更新清单中配置可访问的对象存储或 CDN 地址。
